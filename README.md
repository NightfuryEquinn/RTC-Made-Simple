# RTC-Made-Simple

This guide explains how to convert the video call functionality into independent NPM packages. For best compatibility, use both packages together while developing.

## RTC-Made-Simple-UI
A simple UI for video call

## RTC-Made-Simple-Server
A simple server for video call

## Example App
Check out an React-Native-NestJS example application in [here](https://github.com/NightfuryEquinn/RTC-Made-Simple)

## Notable Errors
1. Babel configurations
2. App.json native permissions
3. Dependencies versions
4. Android devices tend to crash when remote stream is established
